# fl_list_wheel example

A responsive gallery for every widget in `fl_list_wheel`:

- inline previews with live result panels
- Cupertino / Material wheel styles
- themed bottom sheets via the global `FlListWheel.presenter`
- custom Cupertino presenter and inline `FlPickerSession` examples
- light / dark theme toggle

Web demo: https://wayaer.github.io/fl_list_wheel/example/app/web/index.html#/

## Run

```sh
flutter pub get
flutter run
```

Open on the web:

```sh
flutter run -d chrome
```

Build the GitHub Pages demo:

```sh
./build_web.sh
```
